## About the Repository

Welcome to **Python Practice 2026** — my learning and practice repository for Python programming and the concepts covered in my Applied Artificial Intelligence studies.

This repository brings together practical exercises, examples, experiments, and notes based on coursework and additional online learning resources. It is a space to strengthen programming fundamentals, apply new concepts, track progress, and gradually build towards data-driven and intelligent digital solutions.

The repository will evolve as I work through the programme, so its contents may change as new topics and projects are added.

## Learning Goals

The programme is designed to build a strong foundation in:

- **Programming:** Develop problem-solving skills and write clear, structured code.
- **Data preparation:** Acquire, clean, transform, and prepare data for analysis and modelling.
- **Machine learning:** Understand, develop, and evaluate machine learning models.
- **Intelligent systems:** Explore computational intelligence and practical AI applications.
- **Data visualisation:** Communicate patterns, findings, and insights through meaningful visualisations.
- **Cloud and deployment:** Work with cloud services and learn how to deploy and maintain AI solutions.
- **Responsible AI:** Consider ethical guidelines and responsible practices when developing intelligent systems.

By combining theory with hands-on exercises and applied projects, the goal is to become confident in identifying data-driven problems, evaluating possible approaches, and communicating solutions effectively — both independently and collaboratively.

## Getting Started

### Prerequisites

- Python 3 installed on your computer.
- Git installed if you want to clone the repository.

Check your Python installation:

```bash
python3 --version
```

### Clone the repository

```bash
git clone https://github.com/Paris2020/python-prac-2026.git
cd python-prac-2026
```

### Run a practice file

For example:

```bash
python3 main.py
```

To run the Module 3 practice file:

```bash
python3 prac-module-3.py
```

> **Note:** These files are learning exercises. Some scripts request input in the terminal, and the examples are intended to be run individually as you work through the code.
